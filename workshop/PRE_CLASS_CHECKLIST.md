# Recording Agent Starter 课前检查

## 讲师准备

- [ ] 使用与学员将拿到的同一候选 commit 构建 ZIP。
- [ ] 在隔离目录校验 ZIP、安装、CLI help、`doctor` 和 `sample`。
- [ ] 确认候选包不是公开 Release，不包含私人配置、真实录音或 Transcript。
- [ ] 准备断网可打开的 Slidev 静态 HTML 和 PDF 兜底。
- [ ] 准备一条不含敏感内容的约 60 秒测试录音。
- [ ] 准备只发给讲师本人的 P2P 目标作为演示目标。
- [ ] 预留 sample-only 路线；真实授权失败时不伪装完整 Loop 已完成。

## 学员设备

- [ ] macOS 可用；Windows 仅按 beta 前台路线参与。
- [ ] Node.js `>=20.12`。
- [ ] npm 可用。
- [ ] Codex CLI 已安装并登录。
- [ ] `lark-channel-bridge` 已安装。
- [ ] `lark-cli` 已安装。
- [ ] 有本人可读写的本地 Markdown 目录。
- [ ] 有足够磁盘空间安装依赖和保存本地记录。

## 飞书与权限

- [ ] 学员使用自己的飞书应用，不共享 app secret 或 token。
- [ ] user 身份已授权妙记读取、Drive 上传和所需 IM 能力。
- [ ] bot 身份可以只向本人或明确私人测试群发送确认单。
- [ ] active Bridge profile 已唯一确定。
- [ ] Bridge 仍是唯一 IM 长连接。
- [ ] 不扩大允许用户范围，不创建面向第三方的测试群发。

## 测试数据

- [ ] 第一条测试录音不含客户名、课程附件、个人隐私或商业秘密。
- [ ] 测试录音约 60 秒，标题明确标注 E2E 测试。
- [ ] 原录音保留，不自动删除。
- [ ] 运行证据只记录去敏命令、时间、版本和聚合计数。

## 开课前停机条件

出现任一情况就停止真实外部写入：

- 发送目标包含他人或存在多个候选。
- 无法证明目标是本人或明确私人测试群。
- `doctor --live` 非 GREEN。
- user/bot 身份与权限不明确。
- 候选包校验失败。
- 只能用 mock、fixture 或截图替代真实链路。

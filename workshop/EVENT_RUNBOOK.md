# 8 月 3 日活动执行总控

适用活动：杭州生财有术 AI 航海实战聚会，主题为 Recording Agent Starter。

本 Runbook 把官方组局要求与本项目的安全门合并成一条现场执行路径。它是执行清单，
不是活动已经完成的证据；所有方框只按真实结果勾选。

## 体验目标

每位参与者离开时，至少获得三类结果：

1. **作品结果**：在本人隔离 workspace 内完成唯一安全 sample；绿灯学员继续挑战真实录音 Loop。
2. **连接结果**：能说出今天认识的两位伙伴，以及活动后准备如何继续连接。
3. **行动结果**：写下一项未来 72 小时内可检查的动作，并发到活动群。

完整真实 Loop 仍以 `doctor --live` 全绿、实时事件、唯一主记录、唯一确认单和本人回复为门。
现场不把 sample、观看演示或预制截图宣布为完整搭建成功。

## 场地与角色锁定

### 场地

- [ ] 容纳实际人数后仍有活动空间，优先岛屿式或便于两人互助的座位。
- [ ] Wi-Fi 实测可用，并准备手机热点作为降级方案。
- [ ] 投影或电视、转接头、声音、分辨率均实测。
- [ ] 插座 / 排插覆盖所有电脑，通道不绊脚。
- [ ] 详细地址、地铁步行、停车入口和费用已发群。
- [ ] 一人一瓶水；可选 10 元 / 人以内果切，不做会打断实操的走动式茶歇。

### 四个轻量角色

同一人可兼任，但活动开始前必须点名。

- [ ] **签到伙伴**：守签到码，核对迟到和未签到人员。
- [ ] **拍照伙伴**：拍个人介绍、分组互助、作品、讲师与完整投影、全员合影。
- [ ] **录音伙伴**：开始时启动飞书妙记，结束后停止并确认文件可访问。
- [ ] **开场回应伙伴**：第二位完成自我介绍，并在首轮提问时先给真实回应，降低沉默成本。

## 分组与互助规则

- 优先按 macOS / Windows 和绿灯程度分组，再考虑业务相近或能力互补。
- 每组 2—3 人；已经完成的伙伴先帮助一位未完成伙伴。
- 先问 AI，再向同组伙伴说明：背景、报错、已尝试动作和需要的帮助。
- 一个卡点超过 5 分钟仍无进展，记录准确阻塞并切回最小 sample，不让全组停住。
- 展示使用 “Yes, and”：先肯定已完成的证据，再给一个可验证的优化建议。
